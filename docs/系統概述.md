## 一、作品簡介

**LifeRPG 生活電量冒險**是一個「會累的 RPG 角色」。玩家把人生目標變成 Boss 戰，用專注時間攻略章節、累積技能經驗值；同時，角色有一條**生活電量**——社交、課業、工作、運動、通勤、家務都會消耗它，休息與恢復行動則會讓它回升。

整個作品是**一個 App、一個網址**。左側（手機為底部）的分頁包含：

- **冒險大廳、人生目標、成長軌跡、技能樹、角色檔案**：專注 Boss 戰、七大領域技能樹、人生目標與成果關卡，遊戲紀錄只存在使用者自己的瀏覽器。
- **生活電量**：用語音或文字新增行程，AI 辨識後依活動類型、人數、熟悉度、強度與時長預測耗電，模擬跨日累積，標出未來七天會過載的日子；也在這裡做排程建議、週回顧與 Outlook 行事曆同步。

第一次進入時會跳出 6 題快篩，算出個人的基礎電量。遊戲角色顯示電量條，AI 嚮導依電量建議「今天適合挑戰哪個 Boss、何時安排恢復」，完成「恢復與休息」又會讓電量回升。產品定位是**自我照顧工具**，不是醫療或心理評估。

## 二、動機與要解決的問題

1. **行事曆只管理時間，不管理能量。** 同樣是兩小時，和熟悉的朋友吃飯、和二十個陌生人參加迎新、熬夜準備期末考，耗掉的心力天差地遠，但行事曆上看起來一模一樣。
2. **疲勞會累積，人卻常常到崩潰才察覺。** 連續幾天排滿行程，前一天沒補回來的疲憊會拖累隔天。
3. **成長工具只鼓勵「再多做一點」。** 多數習慣養成或遊戲化工具只獎勵投入時間，沒有把休息當成成長的一部分，容易讓人過勞。

本作品把「能量」變成看得見的電池，並把恢復行動設計成會累積經驗值的技能，讓使用者在規劃挑戰時，也規劃恢復。

## 三、目標使用者與使用情境

- **大專學生**：課業、社團、打工、社交同時進行，常在期中期末或迎新季節過載。
- **剛進入職場的年輕上班族**：會議密集、需要經營人際關係，又想持續自我成長。

典型情境：開學週有迎新、社團說明會和第一週課程。使用者在「生活電量」分頁用語音說出行程（或直接從 Outlook 匯入），系統標出週三、週四電量會低於 30%，而且週四的低電量是週三累積下來的；冒險大廳的 AI 嚮導建議週三只挑戰 20 分鐘的 Boss，並在迎新結束後安排 20 分鐘的離屏休息。

## 四、系統功能

### 4.1 生活電量

| 功能 | 說明 |
|---|---|
| 人格快篩 | 第一次進入 App 時自動跳出，6 題社交情境題，算出個人的**基礎電量上限**（25–88）與**恢復方式**（獨處充電／和少數人相處充電／混合）；之後可隨時重新快篩。 |
| 新增行程 | 語音、一句話文字或手動表單。**社交活動**（吃飯、會議、約會、上課、派對、其他社交）填人數與熟悉度；**生活活動**（課業考試、工作打工、運動、通勤、家務雜事）填強度 1–5。 |
| 即時估算＋AI 背景修正 | 新增時先以規則式模型立刻回應預估耗電，同時在背景呼叫生成式 AI 重新估算，完成後自動更新。 |
| 語音輸入＋AI 辨識 | 按下「語音輸入」說一句話（例如「後天晚上八點要準備期末考讀書三小時」），由瀏覽器內建的語音辨識轉成文字，再交給生成式 AI 解析成活動類型、人數或強度、時長與時間，自動填好表單；AI 沒把握的欄位會提示使用者確認。句子裡有「明天、禮拜幾」等日期詞時，日期改以規則換算，避免模型算錯。 |
| 跨日累積電量模型 | 每天起床電量 = min(基礎容量, 前一天剩餘 + 基礎容量 × 0.8)。睡一覺只回充八成，前一天的赤字會帶到隔天。 |
| 七天風險預警 | 當天結束時低於 30% 即為風險日，由 AI 產生具體建議（例如在兩場活動之間插入獨處緩衝）；AI 不可用時改用規則式提醒。 |
| AI 排程建議 | 用一句話描述想安排的活動，AI 比較未來七天的電量，建議最適合的日期與時段並標示不建議的日子，按「排進這天」就直接加入行程。 |
| 回顧與校準 | 行程結束後回報「比預期累／差不多／比預期輕鬆」，AI 週回顧統計預測與實際的差距、找出最常被低估的活動類型，並依回報校準個人的基礎容量。 |
| Outlook 行事曆整合 | ①**一鍵加入 Outlook**：產生個人專屬的訂閱網址，按鈕直接開啟 Outlook（個人或學校／公司帳號）的「從網路訂閱」，把行程與電量預警同步進 Outlook；也支援 Apple 行事曆。②**從 Outlook 匯入**：貼上 Outlook 發佈的行事曆連結或上傳匯出的 .ics 檔，系統讀取未來七天的行程（含每週重複的課表），自動判斷類型並估算耗電。 |

### 4.2 冒險（遊戲層）

| 功能 | 說明 |
|---|---|
| 專注 Boss 戰 | 三種計時模式：倒數專注、番茄鐘（自動休息、休息不計時）、正計時的「木樁訓練」。專注時角色自動攻擊 Boss，血量依該回合的專注時間下降。 |
| 經驗值與等級 | 同一天、同一技能每滿 5 分鐘專注得 2 XP，每日上限 100 XP，避免鼓勵過度投入。角色等級與各技能等級分開計算。 |
| 七大領域技能樹 | 學習與知識、語言與溝通、工作與職涯、創作與技術、健康與身體、生活管理、關係與內在成長；可自訂科目。 |
| 人生目標與成果關卡 | 目標拆成 1–8 個成果關卡，由玩家自己確認完成（不是第三方驗證）。 |
| 成長軌跡 | 7／30／90 天累積 XP 曲線、每日紀錄、各領域投入時間。 |
| 生活電量條 | 在冒險大廳與角色檔案顯示今天行程結束後的預估電量、起床電量與行程數；低於 30% 轉為警示色。 |
| AI 嚮導 | 冒險大廳的卡片顯示今天電量、近期風險日與今日建議（建議挑戰的 Boss、專注分鐘數、恢復時段），並標示建議的產生來源。 |
| 恢復即成長 | 完成「恢復與休息」（放鬆練習、離屏休息、休息安排）或「睡前準備」的專注與補登，會自動回報讓電量回升（每分鐘 0.5%，單筆 2–30%），同時照一般規則累積該技能的 XP。 |
| 長期低電量關懷 | 未來七天有 3 天以上低於 30% 時，嚮導提醒使用者可以和信任的人聊聊，或尋求學校輔導中心等專業資源。 |
| 資料自主與 PWA | 遊戲資料存在瀏覽器的 IndexedDB，支援匯出與還原；整個 App 是 PWA，可安裝到 Windows（Edge）、Android 與 iOS 主畫面並離線使用。電量服務連不上時只顯示「離線」，其他功能照常運作。 |

## 五、系統架構

| 元件 | 技術與部署 | 職責 |
|---|---|---|
| LifeRPG App（唯一介面） | 單一 index.html 的 PWA，位於網站根目錄；IndexedDB、Service Worker、Canvas、瀏覽器語音辨識 | 所有畫面：冒險、技能、目標、生活電量、行事曆、AI 嚮導 |
| API 服務 | Next.js 14 Route Handlers，全部跑在 Cloudflare Pages 的 edge runtime；與 App 同一個網域 | 行程、耗電預測、七天電量、風險預警、排程建議、週回顧、Outlook 整合 |
| 資料庫 | Cloudflare D1（SQLite）＋ Drizzle ORM | 匿名使用者的快篩結果與行程（users、activities） |
| AI 供應商鏈 | `lib/ai.ts`：Workers AI（Meta Llama 3.3 70B）→ 規則式估算 | 耗電修正、語音語意解析、風險預警、排程建議、週回顧、AI 嚮導 |
| Microsoft Outlook | iCalendar 訂閱與匯入 | 在 Outlook 看到行程耗電與預警；把 Outlook 行程帶進 App |

主要 API（呼叫方都是 LifeRPG App，Outlook 只讀取訂閱內容）：

| API | 用途 |
|---|---|
| `POST /api/onboarding` | 6 題快篩，建立匿名電量帳號 |
| `POST /api/parse-voice-activity` | 把語音或文字描述解析成行程欄位 |
| `POST /api/activities` | 新增行程：規則式立即回應，AI 背景修正 |
| `GET /api/activities/week` | 七天電量、行程與 AI 風險預警 |
| `PATCH /api/activities/{id}/actual-drain` | 回報實際感受，校準基礎電量 |
| `POST /api/schedule-suggest` | AI 排程建議 |
| `GET /api/review/week` | AI 週回顧 |
| `GET /api/public/battery`、`POST /api/guide/today` | 冒險大廳的電量條、統計與 AI 嚮導 |
| `POST /api/public/recovery` | 完成「恢復與休息」後回報，電量回升 |
| `POST /api/calendar/subscribe`、`GET /api/calendar/{token}.ics` | Outlook／Apple 行事曆訂閱 |
| `POST /api/calendar/import` | 從 Outlook 匯入未來七天行程 |

- **單一 App。** LifeRPG 的原始碼獨立維護，建置時放到網站根目錄；API 與畫面同一個網域，不需要跨站設定。
- **匿名帳號。** 電量服務以匿名 cookie 辨識使用者，不需要註冊；快篩完成即建立帳號。
- **來源檢查。** 寫入類 API 只接受同站請求，其他來源一律回 403；App 的 CSP 只允許連線到本站。

## 六、AI 與 Agent 設計

### 6.1 「規則式估算＋AI 背景修正」

所有 AI 呼叫都經過同一個入口（`lib/ai.ts`），流程是：

1. **規則式模型先回應**：純計算、零延遲，使用者按下送出就看得到結果。
2. **生成式 AI 在背景修正**：以 Cloudflare `waitUntil` 背景呼叫模型，輸出通過 Zod 驗證後才回頭更新資料。
3. **任何一步失敗都不中斷**：AI 逾時、格式錯誤或服務異常時，保留規則式結果，回應中的 `source` 欄位會標示 `rule`。

目前生成式 AI 使用 Cloudflare Workers AI 上的 **Meta Llama 3.3 70B**（符合競賽的模型限制）。供應商鏈另外預留 Azure OpenAI、Groq、OpenAI 的介面，設定金鑰即可依序啟用，不需改程式。

### 6.2 AI 嚮導 Agent

AI 嚮導的輸入是「今天與未來六天的電量、風險日、玩家進行中的目標名稱」，輸出是結構化的今日建議：

```json
{ "bossGoal": "完成心理學課程複習", "focusMinutes": 20,
  "recoveryWhen": "晚上行程結束後 20 分鐘", "message": "今天電量 42%，挑戰 20 分鐘就好，打完記得休息。" }
```

- `bossGoal` 必須是玩家目標清單中的名稱，否則視為不指定。
- AI 失敗時退回規則式建議：電量 ≥ 60% 建議挑戰最重要的目標 40 分鐘；30–59% 建議 20 分鐘並在社交後安排恢復；低於 30% 建議以恢復為主。
- 只送出目標名稱，不送備註、紀錄或其他個人內容。

### 6.3 輸入與輸出驗證

- 所有 API 輸入以 Zod 驗證；所有 AI 輸出以 Zod 驗證後才採用。
- 會呼叫 AI 的路徑先做**危機字詞偵測**：命中時不交給 AI，直接回覆固定文字並提供安心專線 1925。
- 每個 system prompt 都內嵌安全條款：不提供醫療診斷、心理疾病判定或藥物建議。

## 八、理論基礎

1. **外向性人格特質（Big Five Extraversion）**：外向性是五大人格特質之一，是連續的向度（Costa & McCrae, 1992）。偏內向者在社交情境中較快感到疲憊，研究也發現外向行為雖帶來當下的正向情緒，卻與數小時後的疲勞有關（Leikas & Ilmarinen, 2017）。本系統以 6 題情境快篩估計個人的基礎電量上限；快篩為自行設計的自我了解工具，不是標準化心理測驗。
2. **資源保存理論（Conservation of Resources, COR）**：個人的心理資源有限，資源流失會帶來壓力，而且損失會累積（Hobfoll, 1989）。這是「耗電非線性」與「跨日累積」的依據：時間越長、對象越陌生，消耗越快；前一天沒補回來的赤字會帶到隔天。
3. **努力—恢復模型（Effort-Recovery Model）**：工作或學習時付出的努力會造成負荷，需要足夠的恢復才能回到原本狀態（Meijman & Mulder, 1998）。這是把課業、工作、運動等生活活動納入電量，並以強度與時長估算的依據。
4. **恢復經驗（Recovery Experiences）**：放鬆、心理抽離等恢復經驗有助於回復精力（Sonnentag & Fritz, 2007）。這是「恢復與休息」技能讓電量回升的設計依據。
5. **遊戲化（Gamification）**：在非遊戲情境中使用遊戲設計元素（Deterding et al., 2011）。本作品以 Boss 戰、技能樹、經驗值呈現投入與成長，並設定每日 XP 上限，避免鼓勵過度投入。
6. **番茄工作法**：以固定專注時段與短休息交替（Cirillo, 2006），是 Boss 戰番茄鐘模式的依據。

## 九、隱私、安全與倫理

- **遊戲紀錄只在本機**：目標、專注紀錄與 XP 只存在瀏覽器；行程、電量與快篩結果以匿名帳號存在伺服器，AI 嚮導只收到進行中的目標名稱。
- **匿名使用**：電量計以匿名 session 識別，不需要註冊帳號、不收集姓名或信箱。
- **最小化資料**：電量快照 API 只回傳每天的數字與類別合計，不回傳活動細節；Outlook 匯入時行程標題只用來分類，不儲存、不送給 AI；語音由瀏覽器轉成文字後，只把文字送去解析。
- **金鑰只在伺服器端**：API 金鑰以 Cloudflare secret 保存，不進 git、不出現在前端。
- **限流與防濫用**：所有 API 套用每分鐘呼叫上限；Outlook 匯入只接受 Outlook 官方網域的連結，避免被當成跳板。
- **自我照顧，不是醫療**：介面不使用診斷、症狀、治療等醫療用語；危機字詞直接轉介安心專線 1925；長期低電量時提醒尋求信任的人或學校輔導資源。
- **不商品化**：沒有付費、訂閱或金流功能。

## 十、示範流程

1. 打開 `https://liferpg-adventure.pages.dev/?demo=1#demo`，進入示範角色與示範電量。
2. 冒險大廳：生活電量條、AI 嚮導的今日建議、七天電量長條圖與統計；接下來七天中第 3、4、5 天低於 30%，第 4 天起床只剩 46%，是前一天的迎新累積下來的。
3. 開啟一場專注 Boss 戰，結算後取得 XP。
4. 切到「生活電量」，按「語音輸入」說出一個行程，AI 辨識並填好表單，加入後電量條與七天電量立即更新。
5. 補登一段「放鬆練習」，電量回升，「恢復與休息」技能累積 XP。
6. 用「AI 排程建議」找新活動的最佳時間；產生 AI 週回顧。
7. 按「加入 Outlook」，行程與電量預警出現在 Outlook 行事曆；或從 Outlook 匯入課表。
8. 用無痕視窗打開網址，展示第一次進入時的 6 題快篩；把 App 安裝成 PWA，展示離線開啟。
