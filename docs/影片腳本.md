## 拍攝注意

- **語音輸入（分鏡 6）**：自動剪輯版用「打字＋AI 辨識」示範同一個功能。若要拍真的對麥克風說話，請用 Edge 開網址、允許麥克風，說「後天晚上八點要準備期末考讀書三小時」，錄好後替換 `video/clips/06-voice.webm`。
- **Outlook（分鏡 9）**：自動剪輯版只拍到 App 內的「加入 Outlook」按鈕與匯入結果。若要拍 Outlook 網頁版出現行程的畫面，請自己登入 Outlook 後錄一段，替換 `video/clips/09-outlook.webm`。
- **畫面不要出現**：瀏覽器的帳號頭像、書籤列、桌面上的學校資料夾、Cloudflare／GitHub 後台的專案列表。
- **用詞**：自我照顧工具，不說「診斷、治療、症狀」。

## 自動剪輯

在 Windows 的 PowerShell、`video/` 目錄執行（需要 Edge 與 ffmpeg）：

1. `npm install`：安裝 puppeteer-core（使用電腦上的 Edge，不另外下載瀏覽器）。
2. `python make_voice.py`：用 Edge TTS（微軟神經網路語音）產生每段旁白。
3. `node cards.mjs`：產生標題卡。
4. `node record.mjs`：用 Edge 實際操作正式站，錄下分鏡 3–9；`node record.mjs 06` 可只重錄某一段。
5. `python build.py`：依旁白長度剪接 AI 影片、錄影與標題卡，燒入字幕，輸出 `video/out/LifeRPG-demo.mp4`。
6. 錄完後在 WSL 的 `apps/battery` 執行 `npm run db:seed:remote`，清掉錄影時寫入示範帳號的行程。

AI 影片原檔放在 `video/ai/`（不進 git）。
